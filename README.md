# 練習系統

家用線上練習系統，涵蓋國文、英文、數學、理化、生物、自然、社會。

每天自動指派課堂，作答後自動批改客觀題，作文由家長批改。答錯或看過解答的題目會依間隔重複安排複習。難度依答對率自動升降。

線上版：<https://edwardchen17.github.io/education/>

## 設計重點

**解題邏輯取代答案。** 學生卡住時可以自行查看說明來理解，而不是被卡死。系統不顯示「正確答案是 X」，而是逐一說明每個選項為什麼成立或不成立，計算題則提供分步推導。查看的代價是該題不計分，並排入日後複習。

**題目由程式生成。** 數學與理化的計算題以參數化模板隨機產生數值、由程式計算正解，因此練不完，且不涉及第三方題目的著作權。國文閱讀使用公有領域古典文本。

**作答快照。** 每筆作答完整保存當時的題目內容，因此即使日後修改出題程式，歷史考卷也不會變樣。

## 技術架構

純靜態前端部署於 GitHub Pages，資料存於 Supabase（Postgres + Auth + RLS）。無建置步驟、無 npm 依賴。

```
index.html
css/          樣式
js/
  main.js     進入點與路由
  auth.js     家庭驗證、管理者閘門
  db.js       Supabase 存取層（唯一接觸 supabase-js 的檔案）
  cache.js    本機快取與離線佇列
  screens/    各畫面
  engine/     排課、批改、複習、難度、勳章、答案比對、數學式渲染
  bank/       題庫載入與生成器
  ui/         背景繪製、音訊、圖表
data/         靜態題庫與素材
config/       科目、知識點、計分、勳章設定
sql/          資料表結構
test/         Node 無頭測試
```

## 本機開發

```bash
python -m http.server 8123
# 開 http://127.0.0.1:8123/
```

需要以伺服器開啟，因為使用 ES Modules，`file://` 協定不允許模組載入。

執行測試：

```bash
node test/run.js
```

## 資料庫設定

`sql/schema.sql` 貼進 Supabase 的 SQL Editor 執行即可，該腳本可重複執行。

RLS 政策設定為只有登入家庭帳號的連線能讀寫。網頁中的 publishable key 是設計上可公開的，未登入時無法讀寫任何資料。
